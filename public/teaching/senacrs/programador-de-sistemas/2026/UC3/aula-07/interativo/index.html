      O que ficou

      • A mensagem do commit é o que se lê procurando o defeito — e "Desconto de metade da multa" escondeu o > que veio junto. O git log -p mostra a linha.
      • git revert e git restore devolvem a versão que funcionava sem apagar a errada: o histórico guarda tudo, de propósito.
      • É essa mesma garantia que guarda a senha. Senha que entrou num commit público está vazada: o conserto é trocar a senha, e o .gitignore antes do primeiro commit é o que impede a próxima.
